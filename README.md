# 四叶草TV 安装包发布

本仓库仅用于发布四叶草TV各平台安装包，源码不公开。

## 下载

最新版本请前往 [Releases](https://github.com/277383761/siyecao-tv-app/releases/latest) 下载对应平台的安装包。

| 文件 | 适用设备 |
| --- | --- |
| `siyecao-mobile-5.9.11-arm64-v8a.apk` | 四叶草手机版 5.9.11 — 安卓手机 / 平板（64 位，主流机型） |
| `siyecao-mobile-5.9.11-armeabi-v7a.apk` | 四叶草手机版 5.9.11 — 安卓手机 / 平板（32 位，老机型） |
| `siyecao-tv-5.9.11-arm64-v8a.apk` | 四叶草TV版 5.9.11 — 安卓电视 / 盒子，安卓 7 及以上（64 位） |
| `siyecao-tv-5.9.11-armeabi-v7a.apk` | 四叶草TV版 5.9.11 — 安卓电视 / 盒子，安卓 7 及以上（32 位） |
| `siyecao-tv-legacy-5.8.18-armeabi-v7a.apk` | 四叶草TV版 5.8.18 — 安卓电视 / 盒子，安卓 5 / 6 老设备 |
| `siyecao-mac-1.3.10.dmg` | 四叶草TV macOS 1.3.10 — Apple 芯片 / Intel |

> 安装前请先卸载旧版本，或直接覆盖安装。电视端遇到解析失败时优先尝试 32 位版本。

## 主要功能

- 全源聚合播放，自动按线路速度切换，卡顿自动切线
- 播放记录跨端同步：安卓手机、安卓电视、macOS 之间互通，精确到集数与播放进度
- 弹幕匹配、自定义配置源、内置多源自动轮询
- 支持继续观看、搜索、直播
