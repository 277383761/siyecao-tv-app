# 四叶草TV 介绍

- 类tvbox加入了智能源,内置多源自动轮询、如果所有内置源失效时还会自动抓取新源 (解决用户自己找源维护源的烦恼)
- 全源聚合播放，自动按线路速度切换，卡顿自动切线 (解决播放时遇到卡的线路要手动换线路的烦恼)
- 播放记录跨端同步：安卓手机、安卓电视、macOS、Windows 之间互通，精确到集数与播放进度 (解决在公司里看完回家继续看又要重新搜索找某集某分钟的烦恼)
- 永久免费,虽然我老婆觉得搞事情一定要能赚钱才行,觉得好用就扫下面的二维码打赏一下吧.
- 手机端和TV端app可以共存 (解决某些安卓机器如zflip5外接电视时装TV端不用覆盖手机端app)

尊重作者.此项目是基于 https://github.com/FongMi/Release/releases 空壳项目二次编译而成

本仓库仅用于发布四叶草TV各平台安装包.

## 更新记录

### 6.0.9
- 全平台新增一键清空全部播放记录、一键清空全部收藏按钮，样式与应用主题一致
- 同一部电视剧的收藏跨线路合并为一个封面，收藏卡片显示最新集数与播放进度，点击即从上次进度续播
- 聚合首页优先展示电影、电视剧两个基础分类并默认电影；首屏从首条有效电影线路快速出封面，其余分类后台增量补全，滚动继续加载
- 电影分类严格过滤带「第 N 集 / 全 N 集 / 更新至」等剧集标记的条目，电视剧分类同步过滤误入的电影
- 分类切换已加载内容直接复用，不再重新请求；封面图内存缓存，切回分类或从设置返回首页都不会刷新封面
- 疑似成人内容分类（福利、网红主播、写真套图等）统一排到分类列表末尾，电影、电视剧始终最前
- 空分类在确认无内容后自动移除

### 6.0.0
- 全平台版本号统一为 6.0.0，客户端自更新统一指向本仓库
- 跨端「在其它设备播放」：手机 / 电视 / Windows / macOS 任意互推，带线路、集数、进度续播
- 切源严格同片校验：按片名 + 影片形态 + 年份筛选候选，按集名 / 集号对齐同一集，避免切线路后串片、集数错位，播放进度保留
- macOS / Windows 封面右上角新增「在其它设备播放」按钮，播放记录封面删除按钮移至左上角，两端交互一致
- macOS 起播与解析阶段增加「加载中 / 正在解析播放地址 / 正在缓冲」提示，避免等待时无反馈
- Windows 搜索页点击「首页」可直接返回首页
- 弹幕匹配优化：带集数搜索、多 P 视频按分 P 定位、番剧正片库兜底
- macOS / Windows 客户端支持自有更新检查与下载

### 5.9.13 / 5.8.20 / macOS 1.3.15
- 同步改为全量，不再增量；约 1 分钟一次，暂停播放和返回 App 时各同步一次
- 自动切线：出画面后 5 秒内不切走，起播缓冲不再判定为卡顿
- 网络仍在 300KB/s 以上时多等一会儿再切线路
- 首页预设源必须推荐栏有影片且封面能真实加载，macOS 端同步生效
- 修复安卓 5/6 首页选源界面卡顿

### 5.9.13 / 5.8.20 / macOS 1.3.15
- 修复弹幕按集匹配：电视剧第 2 集及以后不再错配第 1 集的弹幕
- 同步记录合并：同一影片多条播放记录只保留最后播放的一条，最新记录排「继续观看」最前
- 同步提速：轮询缩短至 10 秒 + 增量拉取，配套自建同步服务端 1.3.3
- 修复安卓 5/6 开机广播崩溃（网络回调 API 兼容）
- macOS：空格键暂停/播放、按集名精确续播

### 5.9.11 / 5.8.18 / macOS 1.3.10
- 修复跨端同步集数错误：同步记录新增集名字段，其它平台续播可精确对到同一集
- 修复同步拉取时因时间戳比较导致云端记录不覆盖本地的问题
- 修复退出播放页后仍弹出线路切换提示的问题
- 修复退出播放页偶发崩溃的问题
